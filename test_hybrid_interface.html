POST /api/upload-and-process

Cet endpoint hybride : upload les images → génère des URLs locales → appelle le workflow n8n → retourne le résultat complet

Étapes du workflow
  1. Upload et sauvegarde des images
  2. Génération d'URLs locales
  3. Appel du webhook n8n avec contenu + URLs
  4. Analyse OpenAI du contenu
  5. Sélection automatique du template
  6. Création du document InDesign
L'IA OpenAI analysera ce contenu pour générer automatiquement le titre, sous-titre et structurer le texte.
